# Проект: портфолио видеомонтажёра и моушен-дизайнера

## Цель
Одностраничный сайт-портфолио. Главный приём — «полёт камеры» по оси Z сквозь кадры с работами (видео) и текстовые карточки. Посетитель должен за 5 секунд понять, кто это и что он делает, посмотреть работы и оставить заявку.

## Домен
- **Работа (project)** — ролик: монтаж или моушен. Есть название, клиент, год, категория, ориентация кадра (горизонтальный 16:9 / вертикальный 9:16), видео, постер, короткое описание.
- **Профиль** — имя, роль, короткое «о себе», город, e-mail, соцсети, ссылка на шоурил.
- **Заявка (contact request)** — имя, e-mail, сообщение, бюджет (необязательно). Владелец читает заявки в админке.

## Состав
- `/` (корень репозитория) — фронтенд на Next.js 15 (App Router, SCSS modules, gsap/clsx уже в зависимостях).
- `backend/` — API на NestJS + SQLite (better-sqlite3), загрузка медиа на диск.

## Границы (что НЕ входит сейчас)
- Визуальная админ-панель (UI). Есть только admin API; UI — отдельный пакет.
- Отправка уведомлений о заявках (e-mail/Telegram) — открытый вопрос.
- Мультиязычность, CMS, транскодинг видео, CDN.
