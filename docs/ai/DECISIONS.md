# Журнал решений

## 2026-10-24 — Хранилище: SQLite (better-sqlite3) без ORM
Контекст: 3 таблицы, один владелец, малый трафик. Prisma 7/8 и TypeORM 1.x — свежие мажоры.
Решение: better-sqlite3, SQL в репозиториях, миграции по `user_version`. Тесты — на `:memory:`.
Последствия: деплой на сервер с постоянным диском; переезд на Postgres — замена репозиториев. См. research/001.

## 2026-10-24 — Админ — одна учётка из env
Решение: `ADMIN_EMAIL` + `ADMIN_PASSWORD_HASH` (bcrypt), JWT HS256 без refresh-токенов. Таблицы пользователей нет.

## 2026-10-24 — Тип загруженного файла определяется по сигнатуре
Решение: `mimetype` и расширение от клиента не доверяем; имя файла генерируем (`uuid.ext`), расширение берём из определённого типа.

## 2026-10-24 — Визуал: направление «pinned poster», Z-полёт остаётся главным приёмом
Решение: имя разрезано по двум углам и закреплено, между ними летит камера сквозь работы. Сцена закреплена дольше, чем 3 экрана (по экрану на работу) — осознанное отступление от правила направления, потому что Z-полёт — авторская идея сайта. Тайм-код как индикатор прогресса (идея: таймлайн монтажёра становится полётом камеры).

## 2026-10-24 — Шрифт: TikTok Sans вместо выпавшего Bricolage Grotesque
Контекст: в Bricolage Grotesque нет кириллицы. Перевытянут слот type → TikTok Sans (есть кириллица и ось ширины). Подключён через Google Fonts `<link>` — в next 15.0.4 `next/font` его не знает.
Решение: одно семейство; дисплей — 800, ширина 150 %, капс; текст — обычная ширина 400/500.

## 2026-10-24 — Медиа на фронте
Решение: пути `/media/*` из API префиксуются `NEXT_PUBLIC_API_URL`, остальные (`/assets/*`) отдаёт Next из `public/`. Без API страница работает на `src/app/data.ts`.

## 2026-10-24 — Формат slug строже контракта
Решение: slug — `^[a-z0-9]+(?:-[a-z0-9]+)*$` (без ведущих/двойных дефисов), до 80 символов. Контракт в плане уточнён этим решением.

## 2026-10-24 — Правки по ревью 001
Пауза скрытых видео в ленте, сброс inline-стилей при reduced motion, шоурил через `resolveMediaUrl`, пустой список работ из API не заменяется демо, `IsMediaUrl` отсекает `/\host`, mp4 принимается только с известными brand (`isom`, `mp42`…), `preload="metadata"` в hero, CORS-пример включает порт 3001.

## 2026-10-24 — Отказ от минимализма (план 002)
Контекст: владелец (Кирилл Зотов) попросил насыщенный визуал по примерам 21st.dev / React Bits / Aceternity.
Решение: тёмная тема, шейдерный фон на каждую секцию, стекло, градиентные кнопки, 3D-карточки. Направление «pinned poster» и правила taste-skill (без градиентов, стекла, свечения) больше не действуют. Закреплённое имя по углам убрано, h1 — в hero.

## 2026-10-24 — WebGL-фоны: ленивый монтаж и локальная правка React Bits
`LazyBackground` держит живыми 2–3 контекста. В компонентах React Bits `loseContext()` в cleanup вызывается только если canvas уже не в DOM: StrictMode в dev повторно запускает эффект на том же canvas, и потерянный контекст давал белый фон.

## 2026-10-24 — План 003: тестовая тема Cyberpunk 2077, hero и спираль по sybiosme.com
Контекст: владелец отклонил набор шейдерных фонов из 002 как несочетаемый.
Решение: удалены Galaxy, Prismatic Burst, Grid Scan, Grainient, Gradient Waves, ATC и `@paper-design/shaders-react`. Единый фон — точечная сетка и сканлайны в CSS. Палитра: чёрный, жёлтый `#fcee0a`, циан `#00f0ff`, красный `#ff003c`. Шрифты: Tektur, Exo 2, Share Tech Mono (замены фирменных шрифтов игры, у которых нет кириллицы). Hero — halftone-шейдер по шоурилу и вордмарк фамилии на всю ширину. Z-полёт заменён спиралью карточек (CSS 3D); 3 работы повторяются по кругу до 14 карточек. Тема тестовая, откат — через токены в `globals.css`.

## 2026-10-24 — План 004: категории, согласие, отдельные страницы
- Категории работ: reels, ads, motion, corporate, clips (миграция 2: `editing` → `corporate`). Контракт в плане 001 обновлён.
- Заявка без `consent: true` отклоняется (400); сервер пишет `consented_at`.
- Cookie: сайт сам cookie не ставит; выбор посетителя — в localStorage (`cookie-consent`), аналитику подключать только при `all`.
- Общая оболочка страниц перенесена в `app/layout.tsx` (профиль грузится там же), плеер — через контекст.

## 2026-10-30 — План 005: без форм, S3, админка
- Форма заявок, согласие и cookie-баннер удалены; миграция 3 удаляет `contact_requests`. Сайт не собирает персональные данные → по 152-ФЗ уведомление в РКН не нужно. При возврате форм или Метрики решение пересматривается.
- Медиа: `STORAGE_DRIVER=local|s3`; в S3 файл грузится из браузера по подписанной форме, сервер проверяет сигнатуру после загрузки (`confirm`).
- Админка — `app/admin` (Next, без оболочки сайта, noindex), токен в sessionStorage. Сайт — группа `app/(site)`.
- Карточки «Что я делаю» и строка статуса в hero — данные API (`/api/services`, `profile.availability`).
- Владелец — в Москве, работает по всей России.

## 2026-10-30 — План 006: категории в БД, ЧПУ, мета-теги
- Категории — таблица `categories`; работа хранит slug категории, внешний ключ с `ON UPDATE CASCADE` переносит смену адреса на работы, `ON DELETE RESTRICT` не даёт удалить категорию с работами.
- Карточки услуг хранят id категорий и выбранной работы (смена slug их не ломает); API добавляет slug при чтении.
- Адреса категорий — `/works/<slug>`; скрытая категория → 404, её работы остаются в «Все работы».
- Мета-теги: у категорий — свои поля, у страниц — настройка `seo`; пустые поля → значения по умолчанию из профиля.
- Hero: без кнопки «Обсудить проект»; «Шоурил» — только если шоурил задан в профиле (фон hero по-прежнему берёт первую работу).
