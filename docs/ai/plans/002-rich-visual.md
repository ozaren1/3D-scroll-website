# 002 — Насыщенный визуал: шейдерные фоны, новый hero, 3D-карточки
Статус: done · Дата: 2026-10-24

## Цель и границы
Владелец (Кирилл Зотов) попросил уйти от минимализма и внедрить компоненты по присланным примерам:
- hero: 21st.dev `@reuno-ui/hero` (полноэкранный mesh-градиент на шейдере, крупный заголовок из трёх стилей, две кнопки, вращающийся круглый бейдж) и `@sensewood8/responsive-hero-banner` (стеклянная навигация-пилюля, бейдж «New», заголовок с засечками, ряд логотипов);
- фоны: xordev ATC shader, React Bits Galaxy, Prismatic Burst, Grid Scan, Grainient, Gradient Waves (с параметрами из ссылки владельца);
- Aceternity 3D Card Effect.

**Не входит:** бэкенд (кроме имени в сиде), админка. Правила «без градиентов/стекла/свечения» из taste-skill здесь сознательно отменены пожеланием владельца.

## Решения
- Тема тёмная. Палитра из параметров Gradient Waves владельца: индиго `#3e4ba6`, перивинкл `#9fa2ff`; тёплый акцент `#ff7a3d` (как в reuno-hero) для главных кнопок.
- Шрифты: TikTok Sans (как было) + Playfair Display italic (кириллица) для акцентной строки заголовка.
- Каждой секции свой фон, по одному на секцию:

| Секция | Фон |
|---|---|
| Hero | MeshGradient (`@paper-design/shaders-react`, Apache-2.0) |
| Лента работ (Z-полёт) | Galaxy |
| Обо мне | Prismatic Burst |
| Услуги (3D-карточки) | Grainient |
| Этапы работы | Grid Scan |
| Контакты | ATC shader (XorDev, свой WebGL2-раннер) |
| Футер | Gradient Waves (параметры из ссылки) |

- Фоны монтируются лениво (`LazyBackground`: IntersectionObserver, монтаж за экран до появления, размонтаж далеко за пределами), чтобы одновременно жило 2–3 WebGL-контекста. Внутри компонентов React Bits уже есть пауза вне экрана и учёт reduced motion.
- Исходники React Bits (MIT + Commons Clause) кладём в `src/components/backgrounds/` с заголовком лицензии. Исходник 21st-hero закрыт регистрацией — реализуем по превью сами.
- Закреплённое имя по углам убираем: имя теперь в hero (h1).
