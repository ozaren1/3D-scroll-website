# 012 — Метрика с согласием, верификация поиска, курсор, карточки работ
Статус: done · Дата: 2026-11-15

## Цель и границы
Правки владельца: Яндекс Метрика (с Вебвизором), мета-теги Google и Яндекс, курсор в стиле сайта, на `/works` карточки играют при наведении и наклоняются к курсору.
**Не входит:** уведомление Роскомнадзора об обработке ПДн (решает владелец), cookie-баннер для других сервисов.

## Решения
- Метрика грузится только после «Принять» в cookie-баннере (`lib/consent.ts`, ключ `cookie-consent:v2`); «Только необходимые» — без Метрики. `<noscript>`-пиксель из сниппета не ставится: он считает без согласия. В админке счётчика нет (свой layout).
- Переходы внутри сайта отправляются как `hit`.
- Верификация — через `metadata.verification` в корневом layout.
- Курсор — SVG в CSS только для `pointer: fine`; над ссылками и кнопками — прицел.
- Политика конфиденциальности описывает Метрику и отзыв согласия (кнопка «Изменить выбор cookie»).
