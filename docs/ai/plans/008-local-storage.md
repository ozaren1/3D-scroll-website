# 008 — Медиа на диске сервера вместо S3
Статус: done · Дата: 2026-10-31

## Цель и границы
Владелец хранит контент на своём VPS (диск ~60 ГБ). S3 убираем совсем: файлы идут через API на диск (`UPLOAD_DIR`), отдаются по `/media/…`.

1. Удалить драйвер S3: `s3-storage.service`, `presign`/`confirm`, `STORAGE_DRIVER`, `S3_*`, зависимости `@aws-sdk/*`.
2. Лимит видео настраивается (`MAX_VIDEO_MB`, по умолчанию 2048), картинки — 10 МБ.
3. Защита диска: загрузка отклоняется (507), если после неё на диске останется меньше `MIN_FREE_MB` (по умолчанию 2048).
4. Неиспользуемые файлы удаляются: раз в час (и при старте) сервер удаляет из `UPLOAD_DIR` файлы, на которые 24 ч не ссылается ни одна работа и ни одна настройка (профиль, шоурил); брошенные временные `.upload-*` старше 24 ч — тоже. Предохранители: при пустой таблице работ или доле удаляемых > 25 % — ничего не удаляется.
5. Админка: загрузка всегда через API; показ занятого и свободного места.
6. Долгая загрузка больших файлов: таймаут запроса Node (по умолчанию 300 с) поднимается до 2 ч.
7. Документация: README (Caddy отдаёт `/media` с диска, лимиты прокси, бэкап папки), ARCHITECTURE, DECISIONS, STATUS.

**Не входит:** докачка (resumable upload), перекодирование видео, деплой.

## Контракт API
- `POST /api/admin/uploads` (multipart, поле `file`, JWT) → `201 {url:"/media/<uuid>.<ext>", kind, size}`; `400` — нет файла / неизвестный тип; `413` — больше лимита; `507` — мало места.
- `GET /api/admin/uploads/usage` (JWT) → `200 {usedBytes, files, freeBytes, totalBytes, maxVideoBytes, maxImageBytes}`.
- Удалены: `POST /api/admin/uploads/presign`, `POST /api/admin/uploads/confirm`.

## Тесты
- unit: уборщик (не трогает свежие, используемые и чужие по имени файлы; удаляет старые неиспользуемые и брошенные временные).
- e2e: 401 без токена, загрузка, 413, `usage`, 404 на `presign`.

## Критерии готовности

## Риски
- Уборщик удаляет файлы: удаляем только имена вида `<uuid>.<ext>`, старше 24 ч и без ссылок в БД. Ссылку ищем по имени файла во всех `projects.video_url/poster_url` и во всех значениях `settings`.
- Диск = единственная копия контента: нужен бэкап `UPLOAD_DIR` и БД (описать в README).
