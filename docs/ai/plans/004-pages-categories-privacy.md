# 004 — Страницы «Обо мне» и «Все работы», категории, политика и cookie
Статус: done · Дата: 2026-10-24

## Цель и границы
Правки владельца:
1. Блок работ на главной стоит слишком низко: большой верхний отступ, контент не по центру.
2. «Обо мне» убрать с главной на отдельную страницу.
3. Политика конфиденциальности для форм и баннер согласия на cookie.
4. В «Что я делаю» под каждой карточкой — пример работы.
5. Отдельная страница со всеми работами по категориям: рилсы, реклама, моушен и т. д.

**Не входит:** UI админки, аналитика (баннер готовит место под неё, но счётчиков нет), юридическая экспертиза текста политики.

## Контракт API (изменения)
- `Category` = `"reels" | "ads" | "motion" | "corporate" | "clips"` (было `editing | motion`).
  Подписи: Рилсы и вертикальные · Реклама · Моушен-дизайн · Корпоративное видео · Клипы.
  `GET /api/projects?category=` принимает новые значения, неизвестное — 400.
- Миграция 2: пересборка `projects` с новым CHECK; `editing` → `corporate`. В `contact_requests` добавляется `consented_at TEXT`.
- `POST /api/contact`: новое обязательное поле `consent: true` (иначе 400). Сервер пишет `consented_at`. В admin-ответе `ContactRequest.consentedAt: string | null`.

## Решения
- Маршруты фронта: `/` (hero, работы, услуги, этапы, контакты), `/works` (все работы, фильтр `?category=`), `/about`, `/privacy`.
- Навигация: Работы → `/works`, Обо мне → `/about`, Услуги → `/#services`, Контакты → `/#contact`.
- Пример под услугой: первая работа категории услуги, иначе — из запасной категории; ссылка «Все работы категории» ведёт на `/works?category=…`.
- Cookie: сайт сам cookie не ставит; выбор посетителя хранится в `localStorage` (`cookie-consent`: `all` | `necessary`). Баннер появляется, пока выбора нет. Текст политики — по Закону РК «О персональных данных и их защите» № 94-V от 21.05.2013, с пометкой о проверке юристом. Реквизиты оператора — образцы.
